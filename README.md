# Campus Guia — protótipo

Abra `index.html` no navegador.

O arquivo que será mais alterado quando você tiver a planta real é `js/dados.js`: nele estão os locais e as conexões.

A arquitetura inicial é:
- HTML/CSS/JavaScript;
- mapa em SVG;
- locais/caminhos cadastrados;
- BFS para rota;
- personagem animado;
- QR Code representado inicialmente por URL `?ponto=...`;
- futura integração com Arduino.

Ainda é um mapa provisório: os nomes, coordenadas e caminhos precisam ser substituídos pela estrutura real do campus.
